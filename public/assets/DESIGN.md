# Verity visual assets

The current interface uses a sage, mist and teal palette, a geometric V emblem, DM Sans and Instrument Serif. `verity-field.svg` is the current original vector hero illustration. The coral-and-charcoal `verity-sculpture.png` is an earlier generated artwork retained with its creation prompt below. Font licenses are included in this directory. The reference URL supplied in the conversation could not be reached during implementation, so no reference content was copied.

`logo.svg` is the scalable application emblem. `icons.svg` contains the matching interface icons. Both are project-native vectors.

`verity-sculpture.png` was generated with the built-in image generation tool using this prompt:

Use case: stylized-concept. Asset type: premium web application hero artwork, landscape 3:2 composition. Create an immaculate high-end studio product rendering for Verity, a news verification application. A large sculptural letter V formed from two thick polished smoked-glass and frosted acrylic fins, with warm soft coral-orange light refracting through the cut edges. A tiny warm ivory paper-like layered detail evokes examining evidence, no readable lettering. The V floats slightly above a charcoal-black studio surface with a realistic soft shadow. Dramatic side lighting, tactile material, restrained warm highlights, black and muted coral palette, sophisticated Swiss editorial art direction, macro product photography quality. Center the entire sculpture with generous near-black negative space on all sides. Background perfectly near solid dark charcoal #121316. No text, no watermarks, no UI, no additional symbols, no gradients of vivid purple or blue. This must be an actual dimensional material sculpture, not a flat logo or a stock icon.
